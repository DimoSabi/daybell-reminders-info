A personal Windows utility

Your reminders,
on your desktop.

Daybell Reminders is a Windows tray application that synchronizes selected Google Calendar events and Google Tasks, calculates reminders locally, and submits native Windows notifications. The background application operates independently of browser windows.

Why it requests Google access

Read-only Calendar event access supplies event dates, titles, recurrence instances, cancellations, and reminder overrides. Read-only calendar-list access supplies the selected calendars, timezones, and default reminders. Read-only Google Tasks access supplies task lists, task titles, due dates, and completion or deletion status.

Daybell cannot create, edit, complete, or delete Google events or tasks through these permissions.

Local scheduling, clear limits

Calendar popup reminders follow the synchronized event or calendar settings. The public Google Tasks API provides a due date without its scheduled time or recurrence rule. Date-based tasks therefore use a configurable local reminder time, initially 9:00 AM in the Windows timezone. Per-task overrides remain on the laptop and do not sync to Google.

The laptop must be awake and the user signed in for visible desktop reminders. Windows notification preferences and Do Not Disturb apply. A notification submitted to Windows does not prove that it was seen.

Data stays with your installation

Google authorization uses the system browser. Credentials are protected with Windows DPAPI for the current Windows user. Scheduling data is cached locally with restricted user-level file access. Daybell has no developer-operated data server, analytics, advertising, or subscription.

Read the privacy policy for data handling and deletion details, and the terms of use for operating limits.
